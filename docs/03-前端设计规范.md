# 前端设计规范（前端设计）

> 大学生知识管理与反思平台 — 前端视觉与交互设计体系
> 版本：v1.0 | 日期：2026-10-10
> 适用范围：`frontend/src/` 下全部页面与组件

---

## 1. 设计理念

| 维度 | 定位 |
|------|------|
| 风格 | 深蓝科技风（Dark Tech） |
| 材质 | 毛玻璃（Glassmorphism）+ 发光边框 |
| 主色 | 青色 `#06b6d4` 作为全局强调色与视觉锚点 |
| 背景 | 深蓝渐变星云感，营造"知识星空"意象 |
| 基调 | 精确、克制、微光、呼吸——避免高饱和堆砌，用低透明叠加与发光表现层次 |

三条设计原则：

1. **一色贯穿**：以青色为唯一强调色，主按钮、激活态、图表、发光全部取自同一色系（`#06b6d4` → `#0078d4`）。
2. **毛玻璃分层**：用半透明面 + `backdrop-filter` 建立玻璃层次，而非纯色块堆叠。
3. **发光即状态**：hover / active / focus 通过青色光晕强弱表达，而非大色块变化。

### 2.4 材质与阴影

```css
/* 玻璃卡片 */
background: rgba(22, 27, 34, 0.5);
border: 1px solid rgba(255, 255, 255, 0.1);
border-radius: 16px;
backdrop-filter: blur(16px);
-webkit-backdrop-filter: blur(16px);
box-shadow: 0 0 0 1px rgba(255, 255, 255, 0.05), 0 4px 24px rgba(0, 0, 0, 0.2);
```

| 层级 | 阴影 |
|------|------|
| 卡片常规 | `0 0 0 1px rgba(255,255,255,0.05), 0 4px 24px rgba(0,0,0,0.2)` |
| 卡片 hover | `0 0 0 1px rgba(6,182,212,0.12), 0 8px 32px rgba(0,0,0,0.3)` |
| 弹窗 | `0 8px 40px rgba(0,0,0,0.4)` |
| 发光 | `0 0 12px rgba(6,182,212,0.15)` → hover `0 0 16px rgba(6,182,212,0.25)` |

模糊半径约定：卡片 `16px`、顶栏 `20px`、Loading `4px`。

### 2.5 动效

- **统一过渡**：`transition: all 0.2s ease`（交互元素）/ `0.25s ease`（卡片）
- **缓动函数**：`ease` / `ease-in-out`
- **无障碍**：`@media (prefers-reduced-motion: reduce)` 下停用空状态呼吸动画

详见 [第 7 节 交互动效清单](#7-交互动效清单)。

## 5. 页面设计

### 5.1 知识花园（Dashboard）

- 根容器：`.dashboard-page`
- 结构：
  1. 问候区 `.hero`：动态时段问候（`h1.greeting-text`）+ 副标题 `.greeting-sub`
  2. 花园栅格 `.garden-grid`：左「认知之树」卡 `.tree-card` + 右「宠物家园」卡 `.pet-card`
- 认知之树 `.tree-card`（玻璃卡）：容器 `.tree-container` > `.tree-stage` > `.tree-figure`，内用真实盆景照片 `.tree-img`（素材 `assets/cognitive-tree-cutout.png`，去白底透明 PNG）；树上按成长进度挂载青色发光果实 `.tree-fruit`（随 `tree_growth` 0→100 由 0 长到 8 颗，成熟后点击飞向宠物头像收取）；底部六边形全息底座；下方成长进度条 `.tree-progress`
- 宠物家园 `.pet-card`：宠物头像（`PetAvatar` 组件）+ 等级徽章 + 经验条 + 收取果实/投喂按钮
- 成长引导 `.growth-guide`：`.guide-step` + `.guide-arrow` 三步引导

### 5.2 我的笔记（Notes）

- 根容器：`.notes-page`
- 结构：
  1. 页头 `.page-header-section`：左标题 + 副标题，右 `el-upload` 上传按钮
  2. 统计卡片行 `el-row :gutter="24"` → 4 × `el-col :span="6"` `.stat-card`（高 100px，图标 48×48）
  3. 掌握度趋势图卡 `.chart-card`（高 340px）→ `ref=trendChartRef` 折线图
  4. 知识全息画像雷达图卡 `.chart-card` → `ref=radarChartRef` 六维雷达
  5. 笔记表格卡 `.table-card` → `el-table`（文件名 min 200 / 格式 110 / 上传时间 160 / AI 抽取 min 200 / 操作 200 居中）
- 图表容器统一 `.chart-body`（flex:1, width:100%）

### 5.3 知识图谱（GraphViewer 书架 + 知识书详情）

- GraphViewer 根容器 `.graph-viewer`，当前为**知识书架**视图：
  1. `.shelf-header`：标题 + 操作（新增知识书、发布到广场）
  2. `.book-shelf-view`：书目卡片网格 `.book-card`（点击进入 `/knowledge/book/:bookId`）
  3. `.shelf-empty`：无知识书时 `el-empty`
  4. 弹窗：`AddBookDialog`（新增知识书，宽 440px）、`PublishDialog`（发布到广场，含知识书选择）
- 知识书详情 `BookDetail.vue`（路由 `/knowledge/book/:bookId`，**思维导图编辑模式**）：
  1. 左栏目录树 `el-tree` + 右栏 ECharts 思维导图，**统一只读 `tree` 呈现**（`orient:'LR'`，分支配色、可展开折叠、滚轮缩放，节点不可拖拽），手动创建的书与上传生成的书一致。原可编辑 `graph` 渲染代码（`buildGraphData`/`buildOption`/`ensurePositions`/拖拽持久化等）已彻底删除，仅保留 tree 一条渲染路径
  2. `el-drawer`（rtl）节点详情：掌握度进度 + 表单 + 来源描述 + AI 生成总结
  3. 顶部按钮：返回书架 / 新增目录 / 新增知识点 / AI 辅助（校验整本书、辅助构思、直接生成）
  4. 组件：`NodeContextMenu`（节点与空白右键菜单）、`AIAssistPanel`（AI 校验/构思抽屉 + 生成预览弹窗）

### 5.4 反思中心（Reflection）

- 根容器：`.reflection-page`（`max-width: 1000px` 居中单列）
- 结构（按题目循环，问题区/作答区/AI 反馈 + 底部历史）：
  1. 问题区 `.today-card > .question-item`：题号徽章 `.q-badge` + 知识点 `el-tag.q-tag`
  2. 作答区 `.answer-input`：`el-input` 文本域（`:rows="4"`）+ 语音输入/提交
  3. AI 反馈区 `.ai-feedback-block`：`.radar-container`（240×200）三指标雷达（概念/逻辑/举例）+ 掌握度 `el-progress` + 三项评分 + 薄弱点/建议/资料
  4. 历史卡 `.history-card`：自定义时间线 `.timeline-list` + `.history-rate`（星星）
- 无当日问题时 `.empty-today`（内嵌 `el-empty`）

### 5.5 数字分身（Avatar）

- 根容器：`.avatar-page`
- 布局：`el-row :gutter="24"`，`el-col :span="16"` 配置栏 + `:span="8"` 状态栏
  - 左 `.panel-card.config-panel`：分身预览（自定义头像圆 `.avatar-circle` / `.avatar-photo` + 名称 + 状态标签）+ `el-form`（语气 `el-select`、欢迎语 textarea、知识范围标签、保存/发布按钮）
  - 右 `.panel-card.status-panel`：在线开关 `el-switch` + 分享链接（只读 Input + 复制 + 打开访客页）+ `.stats-grid`（`el-statistic` ×2）+ 高频提问 Top3
- `.panel-card` 内边距 24px、圆角 16px（`min-height` 由内容撑开）；无 ECharts

### 5.6 访客对话（VisitorChat）

- 根容器：`.chat-page`（`height: 100vh`，ChatGPT 风格）；内容容器 `.chat-container`（`max-width: 900px`）
- 结构：
  1. `.chat-header`：固定头部（自定义 `.ai-orb` 头像 + 名称，可选返回）
  2. 消息区：`.msg-body`（`max-width: 78%`），`.msg-bubble`（`line-height: 1.7`），空态 `.chat-empty`
  3. `.chat-input-bar`（`padding: 16px 24px`）：`el-input` + 发送按钮
- 流式回答带来源标注发光标签

### 5.7 知识广场（Community）

- 根容器：`.community-page`
- 结构：
  1. `.hero-section`（`padding: 40px 24px 28px`）：搜索区 + 标题；`.card-grid`（`min-height: 200px`）
  2. `.toolbar`：结果数 `.result-count` + 排序按钮 `.sort-buttons`（最新/最热）
  3. `.card-grid`：`el-row :gutter="24"` → `el-col :xs="24" :sm="12"` `.post-card`（封面 `.stat-item`、`.card-tags`、`.card-footer`）
  4. `.pagination-bar`：`el-pagination` 居中
- 空状态：`el-empty` + `#image` 插槽**自定义"知识星图"SVG**（发光核心 + 卫星节点 + 流动连线 + 旋转轨道，配 `eoHalo/eoSpin/eoFlow/eoFloat/eoCorePulse/eoRipple` 动效）

### 5.8 图谱详情（CommunityDetail）

- 根容器：`.detail-page`
- 结构：
  1. `.back-bar`：返回按钮（`el-button` + 图标）
  2. `.detail-header`：标题 + `.detail-meta`（作者/浏览/点赞/克隆）+ `.detail-tags`
  3. `.graph-section`：ECharts 只读预览（`.graph-dual` 高 560px）
  4. `.action-bar`：点赞 / 一键克隆按钮
- 无节点时 `el-empty`

### 5.9 登录（LoginModal）

- **LoginModal**（唯一入口，`el-dialog` 宽 440px）：`.modal-header`（图标 + 标题）+ `el-form`（手机号、`.code-row` 验证码 + 发送按钮）+ `.tip-bar` 提示（`el-icon` InfoFilled）
- 验证码发送按钮带 `spin` 加载动效

### 5.10 悬浮宠物（PetFloat）

- 固定右下角悬浮 `.pet-float`（64×64，`petIdle` 呼吸浮动；hover 显示 `.pet-bubble` 气泡 + `petBounce` 弹跳）
- 点击展开 `el-dialog` 流式对话弹窗（Linear 风格：毛玻璃 + 青紫辉光；自定义头部 `.pet-dialog-head`、宠物发光光环、流式气泡、输入区、音色选择工具栏、麦克风聆听动效）
- 仅在登录状态下显示

| BookDetail | 树图 tree | 三级目录树思维导图，节点掌握度着色 |
| CommunityDetail | 树图 tree | 只读预览 |

统一约定：

- 背景透明（`background: transparent`），与玻璃卡融合
- 主色取自青色系（`#06b6d4` / `#22d3ee`），配合渐变填充
- 关键元素使用 `shadowBlur` / `shadowColor` 发光
- 拆分线、坐标轴使用弱化灰（`#6e7681` / `rgba(48,54,61,…)`）
- 实例需在 `resize` 时调用 `chart.resize()`，卸载时 `dispose()`

## 8. 代码组织约定

- 单文件组件：`<script setup>` + `<template>` + `<style scoped>`
- **私有样式**写在组件 `<style scoped>` 内；**全局 Element Plus 覆盖**统一在 `styles/main.css`
- class 命名：`kebab-case`，以"页面/区块语义前缀"组织（如 `.pet-home-card`、`.chart-card-header`、`.msg-bubble`）
- Element Plus 深度选择统一用 `:deep()`（如 `.side-menu :deep(.el-menu-item)`）
- 组件通过 `ref` 持有 ECharts 实例，配合 `resize` 监听与 `dispose` 回收
- 玻璃卡片的四件套固定写法：`rgba(22,27,34,0.5)` + `blur(16px)` + `border-radius:16px` + `border:1px solid rgba(255,255,255,0.1)`
