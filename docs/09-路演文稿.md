## 一、一句话定位

**宝藏库（KRP）** 把大学生碎片化的笔记，自动「炼」成结构化知识图谱，用 AI 主动提问逼你反思，最终长成一个**可对外对话、代表你本人的数字分身**。

> 别人做的是「知识仓库」，我们做的是**知识器官**——它会生长、会遗忘、会被唤醒。

---

## 二、我们要解决的真问题

| 痛点 | 现状 | 后果 |
|---|---|---|
| **存而不学** | 笔记散落在备忘录、网盘、PDF 里 | 收藏即遗忘，知识「只进不出」 |
| **学而不固** | 划了就忘，没有反馈闭环 | 投入大量时间，掌握度无从量化 |
| **懂了不等于会讲** | 无人提问、无场景输出 | 知识停在「眼熟」层面，无法迁移 |
| **知识不可迁移** | 个人知识藏在脑子里 | 无法沉淀为可分享、可复用的资产 |

> 一句话：**这一代大学生不缺信息，缺的是把信息变成能力的「加工厂」。**

---

## 三、产品：一条完整的知识闭环

上传 → 理解 → 反思 → 分身 → 社交，五个环节环环相扣：

1. **知识摄取** — 支持 Markdown / Word / PDF / TXT / 图片。图片走多模态 OCR，文本经 LLM 自动抽取，生成一本「知识书」（**书本 → 目录 → 知识点** 三级结构）。
2. **知识图谱** — ECharts 渲染的思维导图 + 目录树双栏视图；节点以 **颜色=分支、光环+尺寸=掌握度** 双通道编码，一眼看清「哪里强、哪里虚」。
3. **反思中心** — 基于间隔重复调度，AI 定时出题；用户文字/语音作答，AI 从 **概念准确性、逻辑完整性、举例合理性** 三维打分，动态更新掌握度。
4. **数字分身** — 把个人知识库发布为一个可对话的 AI 角色，访客无需登录即可基于你的知识提问；用 RAG + 阈值防幻觉，答不上来就坦白「不知道」。
5. **知识广场 + 游戏化** — 优秀知识图谱可一键克隆（Fork）到他人书架；用户养成专属宠物，知识输入驱动「认知之树」结出果实，形成正向反馈。

## 四、技术壁垒：数学建模 × 工程极致

这不是一个「套壳 ChatGPT」的项目，我们在 **算法** 与 **工程** 两端都做到了产品级。

### ① 有「数学灵魂」的成长系统

- **掌握度融合**采用带时间衰减与难度加权的 EMA：

  `new = old · w_old + score · w_new`

  其中 `w_new` 随「距上次复习的天数（半衰期 14 天）」与「当前掌握度越低越难」动态放大——**久未复习、越难的知识点，更新越快**。
- **宠物成长曲线**是边际递减凹函数：

  `g(n) = 100 · (1 − (1 − n/80)^1.35)`

  前期反馈快、后期珍惜感强，并配有**严格反函数**保证增量累加幂等。
- **社区热度**用 Hacker News 式重力模型：

  `hot = 互动量 / (发布时长(小时) + 2)^1.5`

  让「新鲜的好内容」能压过「老帖堆量」。

### ② 工程能力可上生产

- **LLM Provider 抽象层 + 工厂 + 降级**：外部模型超时不再 500，而是优雅兜底；共享 httpx 连接池。
- **可观测性底座**：统一日志 + TraceID + 全局异常，错误统一返回 `{code, message, detail, trace_id}`。
- **Prompt 治理**：集中管理 + 防注入声明；异步知识抽取带重试与状态机（pending / success / empty / failed）。
- **质量**：后端 **223 项测试通过（pytest）**，前端 ESLint + 生产构建全绿，CI 一键可跑。

**技术选型**：Vue3 + Element Plus + ECharts ｜ FastAPI（异步）｜ **Neo4j 原生向量索引**做 RAG ｜ SQLite / PostgreSQL ｜ WebSocket / SSE 流式对话。

- **切入逻辑**：从「考试刚需 + 高知识密度」的大学生场景切入，学习行为高频、成果可量化，天然适合 AI 效果验证与口碑传播。
- **延展空间**：个体 → 学习小组 → 学校/机构 → 企业培训知识库。「数字分身」可平滑演进为**组织级的私有知识智能体**。

## 六、商业模式

1. **C 端订阅（主）**：免费额度 + 会员解锁无限抽取、高级分身、跨设备同步。
2. **B 端授权**：为高校 / 培训 / 企业提供私有化知识图谱 + 数字分身平台。
3. **API / 生态**：开放「笔记 → 图谱 → 分身」能力接口，按调用量/席位计费；知识广场优质图谱可形成内容生态与分成。

## 七、竞争格局与差异

| 类别 | 代表 | 我们的差异 |
|---|---|---|
| 笔记工具 | Notion / Obsidian | 它们是「更好的收纳」，我们是「更强的加工」——自动结构化 + 主动反思 |
| 记忆工具 | Anki | Anki 需手工制卡；我们**从笔记自动生成**问题与图谱 |
| AI 对话 | 通用聊天机器人 | 通用模型无「你的知识」；我们做**个人知识 RAG 分身**，可对外发布 |
| AI 笔记 | 各类 AI 摘要工具 | 多停在「总结」层；我们做到**掌握度量化 + 可对话成人格** |

**护城河 = 数据飞轮**：用户越多 → 图谱与反思数据越多 → 掌握度模型越准 → 分身越好用 → 越愿意沉淀 → 迁移成本越高。
