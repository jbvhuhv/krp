## 4. 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 异步任务方案 | FastAPI BackgroundTasks | 轻量，首版无需 Celery |
| AI 服务架构 | 适配器模式（LLMClient 抽象基类） | 支持切换 LLM 供应商 |
| 测试数据库 | sqlite 内存 + StaticPool | 无需外部依赖 |
| bcrypt 兼容 | 直接使用 bcrypt 库（非 passlib 封装） | bcrypt 5.0 与 passlib 不兼容 |
| SQLite 替代 | PostgreSQL 不可用时改用 SQLite | 本地开发无 Docker，优先保证功能可用 |
| Neo4j 降级 | 不可用时返回空数据/503 | 优雅降级，不崩溃 |
| Redis 降级 | 不可用时万能验证码 123456 | 本地开发无 Redis 时仍可登录 |
| 社区标签过滤 | Python 端过滤（非 SQL contains） | SQLite JSON 列存储 Unicode 转义，SQL 过滤失效 |
| 公开接口认证 | OAuth2PasswordBearer auto_error=False | get_optional_user_id 实现可选认证 |
| 艾宾浩斯调度 | mastery<60 或距今≥7天优先 | 优先提问即将遗忘的知识点 |
| 评分加权 | 概念×0.4 + 逻辑×0.35 + 举例×0.25 | 三维度加权，总分0-100 |
| RAG 防幻觉 | 相似度 < 0.7 直接拦截 | 杜绝编造（US3.5） |
| 分身对话协议 | WebSocket JSON：welcome/sources/chunk/done/blocked | 流式输出 + 来源标注 |
| 前端视觉风格 | 深蓝科技风 + 毛玻璃 + 发光边框 + Linear Aesthetic | 用户明确偏好 |
| 登录架构 | Modal 弹窗（非独立路由） | 单页体验：无路由守卫，登录拦截由 axios 401 拦截器 + 菜单点击触发 |
| 知识图谱结构 | 三级树状：book→category→knowledge | 支持多书本+目录层级+知识点 |
| 目录排序 | Neo4j ORDER BY n.name + tree_nodes 顺序保持 | 按名称升序稳定排序 |
| 安全开关 | `DEBUG` 控制万能码 `123456`；`DEBUG=false` 且 SECRET_KEY 仍为默认值时启动即报错 | 生产禁止硬编码后门与弱密钥 |
| 宠物成长防刷 | 新增 `tree_growth_consumed` 记录已消耗成长，`compute_pending_growth` 只结算新增部分 | 避免同一批知识被反复收取果实 |
| schema 迁移 | `schema_migrations` 改用 SQLAlchemy `inspect()` 反射 + `TIMESTAMP` | `PRAGMA` 不可移植且静默吞异常 |
| 图谱删除语义 | `delete_subtree` 返回删除节点数（0 表示不存在），端点据此返回 404 | 原实现恒返回 1，导致 404 永不触发 |
| 前端时间格式化 | 抽取 `src/utils/format.js`（4 个函数），各页面 import 复用 | 消除 5 处语义各异的重复实现 |
| 栅格响应式 | Notes 统计卡片改用 `:xs/:sm/:md/:lg` span + `min-height` | 修复固定 4 列在窄屏下的文字超框 |
